# The files outside the plugin crates that decide what goes into every plugin archive. Read
# by scripts/check-plugin-version-bump.sh from both trees it compares (a side without this
# file uses the other side's): when one of them changes, every plugin with a
# tasty-plugin.toml needs a version bump, once per release (see docs/ci.md). Fields are
# separated by tabs. A path that ends with "/" stands for every file under it.
#
#   blob    path                    compared by path, file mode, and blob id; a symbolic link
#                                   stops the check
#   script  path                    compared without whole-line comments and blank lines;
#                                   the first line stays when it starts with #!
#   except  path  how  pattern      a part of a script path that does not build or pack the
#                                   archives, left out before the comparison:
#                                     function  the definition of the function named pattern
#                                     line      every line that matches pattern
#                                   then a case statement left with no branch goes too
#   region  path  how  open  close  only the parts that packaging runs, compared like a
#                                   script; every region line of a path is one comparison
#
# A region is found by extended regular expressions on whole lines; a trailing comment and
# trailing blanks do not count, for the markers and for the end of a top or job region:
#   block  from the line that matches open to the next line that matches close
#   line   every line that matches open
#   top    a top-level YAML key: from open to the next line that starts in column 0
#   job    a job of a workflow: from open to the next job or top-level key
# A file that exists without one of its regions cannot be judged (exit 2).
#
# blob and script lines count from either side's list. When the except or region lines of a
# path differ between the two lists, that path counts as changed. On every run the gate also
# stops when a script or a shell region file sources a file this list does not name, when a
# script with except lines defines a function twice, and when a job region uses a local
# action or workflow (./).
